douban 架构图 · 豆瓣榜单 Widget + catalog 服务端

ForwardWidget 插件 → CF /doubanapi 反代 → Go catalog 服务 → 外部数据源（豆瓣 / TMDB / Trakt / Fanart）

请求链路

  • • Widget loadList → GET /doubanapi/catalog/{type}/{id}.json?skip=N
  • • CF Worker 反代 → Go :4000（仅 JSON，无 body 改写）
  • • 榜单分发 → ID 映射 + 图片回退 → 返回 metas
  • • 图片 URL 直出 /url?url=…，App 直连 CF 边缘缓存

缓存与预热

  • • SQLite api_cache TTL 25h · singleflight 请求去重
  • • cron 每日 02:00 全量刷新（榜单 + 年度 + 剧场 doulist）
  • • 随机间隔 5–18s 控制在半小时内 · 失败重试 3 次
  • • ID 映射缺失时后台异步补齐并落库

ID 与图片来源

  • • ID 优先级：tmdb → imdb → douban 兜底
  • • 图片三级回退：TMDB → 豆瓣 → Fanart
  • • 外部 API 全部经 /url 统一代理（POST JSON），GET 可命中 CF 缓存
  • • 部署：Docker alpine + modernc.org/sqlite（无 CGO）
